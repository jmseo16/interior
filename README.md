# 🏠 가구 배치 플로어플래너

이사 전 가구 배치를 시뮬레이션하는 웹앱. `index.html` 파일 하나로 동작합니다.

## 실행

```bash
# 브라우저에서 index.html을 바로 열거나,
python3 -m http.server 8000   # → http://localhost:8000
```

3D 보기는 Three.js를 CDN(jsdelivr)에서 불러오므로 인터넷 연결이 필요합니다.
(오프라인이어도 2D 배치·저장 기능은 모두 동작)

## 기능

- **전체 평면도**: 거실 + 방 3개를 실제 위치 관계대로 한 화면에 표시 (단위: cm)
- **ㄴ자 방 지원**: 방에 모서리 컷(corner cut)을 지정해 ㄴ자 구조 표현, 컷 영역으로는 가구가 못 들어가고 밀려남
- **참고용 공간(zone)**: 현관·욕실·드레스룸·발코니 등 배치 불가 공간을 회색 점선으로 표시
- **문 + 회전반경**: 평면도 기준 문 위치와 스윙 영역을 희미하게 표시, 그 안에는 가구 배치 불가(자동으로 밀려남). 3D에서는 벽이 뚫리고 열린 문짝 렌더
- **창문**: 실제 사진 기준 위치·크기로 2D(하늘색 띠)/3D(유리+프레임, 벽 개구부) 표시
- **50cm 그리드 스냅**: 가구를 드래그하면 50cm 그리드에 자동으로 달라붙음 (gravity)
- **드래그 앤 드롭**: 팔레트 → 평면도로 끌어서 배치, 평면도 밖으로 끌면 배치 해제
- **회전**: 가구 선택 후 `R` 키 또는 회전 버튼으로 90°씩 회전
- **배치 해제**: `Delete` 키 또는 버튼
- **방/가구 편집**: 사이드바에서 방 크기·위치, 가구 치수·색상 추가/수정/삭제
- **3D 보기**: 상단 버튼으로 2D ↔ 3D 전환, 마우스 드래그로 회전·휠 줌 (OrbitControls)
- **세션 저장**:
  - 변경 시 localStorage에 자동저장 (새로고침해도 유지)
  - 이름 붙인 세션 슬롯 저장/불러오기
  - JSON 파일 내보내기/가져오기 (다른 기기와 공유 가능)

## 기본 데이터

실제 아파트 평면도 기준 (발코니 확장 반영, 도면 치수선 mm → cm 환산):

- 방1 (왼쪽 위): 299×417 — 위 발코니 150 확장
- 방2 (오른쪽 위): ㄴ자, 외곽 476×431에서 오른쪽 위 150×130 컷 — 위 130 + 오른쪽 150 확장
- 안방 (오른쪽 아래): 412×386 — 앞 발코니는 가벽으로 분리(미확장)
- 거실: 474×540 — 아래 발코니 200 확장
- 참고용: 현관, 욕실 2개, 드레스룸, 주방·식당, 주방 발코니, 안방 발코니

사이드바의 **방 목록 / 편집**, **가구 목록 / 편집**에서 수정하거나,
`index.html`의 `defaultState()`를 직접 수정하면 됩니다.
